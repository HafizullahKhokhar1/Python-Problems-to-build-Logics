# Python Logic & OOP Problems

This repository contains a collection of Python programming problems designed to strengthen both **logical thinking** and **object-oriented programming (OOP)** skills.

🚀 **What’s inside?**
- ✅ Pure logic problems (no OOP)
    - Prime number checks
    - Fibonacci sequence
    - Duplicate detection in lists
    - Palindrome checks
    - Custom sorting algorithms
    - Recursion and factorials
    - String and number operations

- 🔥 OOP problems
    - Class and object creation
    - Inheritance and polymorphism
    - Encapsulation and abstraction
    - Simple game designs (like Tic-Tac-Toe)
    - Real-world models (like Bank Account, Library, Student Management)

🎯 **Who is this for?**
- Beginners learning Python fundamentals
- Intermediate programmers expanding into OOP
- Anyone preparing for coding interviews or building a problem-solving portfolio

💬 **Contributions welcome!**
Feel free to submit pull requests with your own problems or solutions.
